# FerroPhase-Q

**Quantum Ferroelectric Phase Transitions**

FerroPhase-Q is a set of Python tools for simulating polarization hysteresis and real-time polarization dynamics in ferroelectric and antiferroelectric materials using a 1D quantum mechanical model built on a DFT-derived energy landscape.

## Workflow

| Step | Script | Purpose |
|------|--------|---------|
| 1 | `generate.py` | Solve the field-dependent Schrödinger equation and compute equilibrium ⟨P⟩(E) |
| 2 *(optional)* | `analyze_v3.py` | Thermal-average analysis of ⟨x⟩, eigenstate inspection, mass and damping estimates |
| 3 | `quantum_v34.py` | Time evolution of the density matrix and wavefunction under AC or DC fields |

---

## Step 1: `generate.py`

Simulates polarization hysteresis loops based on a 1D quantum mechanical model. It computes the average polarization ⟨P⟩ as a function of applied electric field E using a statistical mixture of quantum states. The energy landscape U(P) is taken as input, and the system's response is computed by solving the time-independent Schrödinger equation for a range of field strengths.

### Key features

- Statistical density-matrix formalism to compute ⟨P⟩(E)
- Solves the 1D Schrödinger equation with a field-dependent potential
- Computes thermal occupation of quantum states
- Generates and saves hysteresis loops
- Saves all data (fields, energies, wavefunctions, polarization) to HDF5
- Interactive analysis of eigenstates for any field value

### Input files

1. **`DataMagnitude.txt`** – polarization (C/m²) vs. potential energy (eV)
2. **`PARAM.json`** – simulation parameters:

```json
{
  "Emin": -400.0,
  "Emax": 400.0,
  "stepE": 801,
  "Temp": 300.0,
  "z_star": 6.3244,
  "Vol": 4407.76,
  "mass": 17400.44,
  "num_sol": 80,
  "n": 200
}
```

| Parameter | Description |
|-----------|-------------|
| `Emin` | Minimum electric field (kV/cm) |
| `Emax` | Maximum electric field (kV/cm) |
| `stepE` | Number of electric field steps |
| `Temp` | Temperature (K) |
| `z_star` | Born effective charge |
| `Vol` | Volume of the structure used in the DFT calculations (Å³) |
| `mass` | Particle mass (amu); can be estimated with `analyze_v3.py` |
| `num_sol` | Total number of eigenstates |
| `n` | — |

### Output files

| File | Description |
|------|-------------|
| `P_vs_E.png` | Equilibrium ⟨P⟩(E) plot |
| `P_vs_E.txt` | Tabulated equilibrium ⟨P⟩(E) values |
| `all_simulation_data.h5` | HDF5 file with all simulation results |
| `eigenstates_field_XXX.png` | Potential and lowest eigenstates for the chosen field and for zero field |
| `interpolated_potential.txt` | Interpolated potential |

### Usage

1. Make sure `DataMagnitude.txt` and `PARAM.json` are in the working directory.
2. Run the script to compute and save the hysteresis loop data:
   ```bash
   python generate.py
   ```
3. Use the interactive prompt to analyze eigenstates for selected field values.

## Step 2 (optional): `analyze_v3.py`

Performs thermal-averaging analysis of position expectation values ⟨x⟩ based on the eigenstate data generated by `generate.py`.

### Functionality

1. Loads eigenenergies, eigenfunctions and physical parameters (mass, number of states, electric field values) from `all_simulation_data.h5`.
2. Loads the interpolation grid (x, V(x)) from `interpolated_potential.txt`.
3. Loads analysis parameters from `PARAMS_anal.json`.
4. Computes:
   - the full thermal average ⟨x⟩ over the entire domain;
   - the partial thermal average ⟨x⟩ over a subinterval [`x_min`, `x_max`], only if the probability density in that region is non-negligible.
5. Plots ⟨x⟩ vs. electric field for both the full and partial intervals.
6. Optionally, at a user-specified field (`Field_to_plot`), plots all eigenstates that together contribute ≥ 99% of the thermal probability density at the given temperature.

### Input files

1. **`all_simulation_data.h5`** – eigenvalues/eigenvectors and attributes (from Step 1)
2. **`interpolated_potential.txt`** – columns x, V(x) (from Step 1)
3. **`PARAMS_anal.json`** – analysis parameters:

```json
{
  "Temp": 300,
  "x_min": 0.0,
  "x_max": 1.2,
  "Field_to_plot": 0.0,
  "polar_mode_freq_THz": 18.72,
  "do_frequency_analysis": true,
  "gamma_target_thz": 0.076447
}
```

| Parameter | Description |
|-----------|-------------|
| `Temp` | Temperature (K) |
| `x_min` | Lower bound of the partial-average interval: average displacement of the polar structure w.r.t. the nonpolar/antipolar one (nm) |
| `x_max` | Upper bound of the partial-average interval (nm) |
| `Field_to_plot` | Electric field at which to plot contributing eigenstates (kV/cm) |
| `polar_mode_freq_THz` | Polar mode frequency (THz) |
| `do_frequency_analysis` | If `true` and `polar_mode_freq_THz` is given, suggests a mass that reproduces that frequency (output in mₑ and amu) |
| `gamma_target_thz` | Experimental damping constant (THz); used to compute `gamma_rescale` for Step 3 |

### Output files

| File | Description |
|------|-------------|
| `X_av_and_partial_vs_Field.png` | ⟨x⟩ vs. electric field for full and partial averages |
| `Eigenstates_99percent.png` | Eigenstates contributing ≥ 99% of the thermal probability density at `Field_to_plot` |

### Usage

```bash
python analyze_v3.py
```

## Step 3: `quantum_v34.py`

Evolves the density matrix and analytical wavefunction of a ferroelectric/antiferroelectric system under an applied AC or DC electric field.

### Input files

1. **`all_simulation_data.h5`** – eigenvalues/eigenvectors and attributes (from Step 1)
2. **`interpolated_potential.txt`** – columns x, V(x) (from Step 1)
3. **`PARAM_dyn.json`** – simulation parameters:

```json
{
  "Temp": 300,
  "field_type": "ac",
  "E_max": 400.0,
  "E_min": -400.0,
  "num_periods": 1.25,
  "nsteps": 75000,
  "delta_t": 0.01,
  "intrinsic_dynamics": false,
  "P_cen": 0.0,
  "delta_P": 0.00,
  "n_out": 500,
  "relaxation_model": "DMB",
  "thermal_weight": "boltzmann",
  "gamma_rescale": 4.555928e-02,
  "plot_mode": "screen",
  "integrator": "simple"
}
```

| Parameter | Description |
|-----------|-------------|
| `Temp` | Temperature (K) |
| `field_type` | `"ac"` or `"dc"` |
| `E_max` | Maximum electric field (kV/cm) |
| `E_min` | Minimum electric field (kV/cm) |
| `num_periods` | Number of field periods (hysteresis loop length) |
| `nsteps` | Number of simulation steps |
| `delta_t` | Integration time step (fs) |
| `intrinsic_dynamics` | `true` or `false` |
| `P_cen` | Initial condition: center of the wave packet (C/m²) |
| `delta_P` | Initial condition: width of the wave packet (C/m²) |
| `n_out` | Output interval for plotting probability densities (steps) |
| `relaxation_model` | `"DMB"` or `"LO"` |
| `thermal_weight` | Thermostat: `"boltzmann"` or `"zero_weight"` for DMB; only `"boltzmann"` for LO |
| `gamma_rescale` | Damping rescaling factor; can be obtained from `analyze_v3.py` |
| `plot_mode` | Live plotting during the run: `"screen"` or `"none"` |
| `integrator` | `"simple"` or `"predictor_corrector"` (`"simple"` works better for large time steps) |

### Output files

| File | Description |
|------|-------------|
| `simulation_output.txt` | Columns: time (fs), applied electric field (kV/cm), polarization – analytical (C/m²), polarization – density matrix (C/m²), trace of density matrix (real) |
| `polarization_vs_time.png` | Polarization expectation value vs. time |
| `polarization_vs_field.png` | Polarization vs. applied electric field (AC field only) |

### Usage

```bash
python quantum_v34.py
```
